# G&L PDF — mises à jour

Ce dépôt sert de point de mise à jour pour le logiciel **G&L PDF** de G&L Créations.

Le logiciel installé vérifie `latest.json` à chaque démarrage. Si une version plus récente est publiée,
il télécharge `editeur.html`, contrôle son empreinte SHA-256 et l'applique au redémarrage suivant.

Aucun document des utilisateurs n'est envoyé ici : les PDF restent sur chaque ordinateur.
